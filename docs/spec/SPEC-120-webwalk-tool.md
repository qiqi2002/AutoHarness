# SPEC-120: WebWalk Tool

## 1. Goal

Define the minimum Runtime contract for restricted web navigation.

WebWalk is a Runtime tool. It is not a new top-level Action type. The
Orchestrator invokes it through `dispatch.input_source.type=tool`, and Runtime
validates the tool name, arguments, execution limits, and returned object before
placing any candidate payload in `temp_buffer`.

## 2. Tool Name

The canonical tool name is:

```text
webwalk
```

## 3. Arguments

Arguments MUST match `schemas/tools/webwalk-tool-arguments.schema.json`.

### 3.1 `open_url`

```json
{
  "operation": "open_url",
  "url": "https://atcoder.jp/..."
}
```

Runtime MUST reject unsupported schemes and domains outside the configured
allowlist.

### 3.2 `open_link`

```json
{
  "operation": "open_link",
  "link_id": 0
}
```

Runtime MUST resolve `link_id` against the current page's observed links. Runtime
MUST reject `open_link` when there is no current page or the link id is outside
the current page's link range.

## 4. Observation Result

The tool result MUST be an object with:

```json
{
  "operation": "open_url | open_link",
  "page": {
    "url": "string",
    "title": "string",
    "text_excerpt": "string",
    "links": [
      {
        "id": 0,
        "text": "string",
        "url": "string"
      }
    ]
  },
  "webwalk_trace": [
    {
      "step": 1,
      "url": "string",
      "title": "string",
      "links": 0
    }
  ]
}
```

`webwalk_trace` MUST be generated by Runtime from actual executed navigation.
The Orchestrator and Sub-Agent outputs MUST NOT be treated as authoritative
trace data.

## 5. Limits

Runtime MUST enforce:

- allowed domains
- maximum page count
- per-request timeout
- configured request delay
- bounded text and link observations

## 6. Planner Action Schema

Agentic demos MAY use compact model actions:

```json
{"action": "open_url", "url": "https://atcoder.jp/..."}
{"action": "open_link", "link_id": 0}
{"action": "final", "result": {}}
```

Those compact actions MUST be validated against
`schemas/tools/webwalk-planner-action.schema.json` before execution. They are a
demo-facing planner protocol, not replacements for the M1 Action envelope.
